메일 인증 코드 도우미

소규모 내부용 도구 · Windows · 일반 배포하지 않음

무엇을 하는 도구인가

특정 업무 사이트에 로그인할 때 이메일로 오는 2차 인증 코드를 Gmail 에서 찾아 로그인 화면의 인증 칸에 자동으로 넣어 주는 소규모 내부용 도구입니다. 허용된 사용자의 PC 에만 설치되며, 일반에 배포하지 않습니다.

Gmail 을 어떻게 쓰는가

  • 권한은 읽기 전용(gmail.readonly) 하나뿐입니다. 메일을 보내거나 지우거나 바꾸지 않습니다.
  • 제목에 정해진 인증 메일 문구가 들어간 최근 메일만 찾아 6자리 인증 코드를 읽습니다.
  • 읽은 코드는 사용자의 PC 화면에만 사용되며, 어디에도 전송·저장하지 않습니다.

안내

  • 개인정보처리방침
  • Gmail 연결을 끊으려면 Google 계정 → 보안 → 서드 파티 앱 및 서비스에서 이 앱의 액세스 권한을 삭제하면 됩니다.
