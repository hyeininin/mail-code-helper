개인정보처리방침

메일 인증 코드 도우미 · 시행일 2026-11-16

이 방침은 소규모 내부용 도구 "메일 인증 코드 도우미" 가 Google 계정(Gmail) 정보를 어떻게 다루는지 설명합니다. 이 도구는 허용된 사용자의 PC 에서만 실행되며, 외부 서버를 두지 않습니다.

1. 접근하는 정보

  • Gmail 읽기 전용 권한(https://www.googleapis.com/auth/gmail.readonly)만 요청합니다.
  • 이 권한으로 하는 일은 두 가지뿐입니다. (1) 제목에 정해진 인증 메일 문구가 포함된 최근 메일을 검색, (2) 그 메일 본문에서 6자리 인증 코드를 읽기.
  • 연결된 계정이 허용된 사용자인지 확인하기 위해 Gmail 주소(프로필의 emailAddress)를 읽습니다.
  • 그 밖의 메일, 연락처, 첨부파일, 라벨은 읽지 않으며, 메일을 보내거나 삭제·수정하지 않습니다.

2. 정보의 사용

  • 읽은 인증 코드는 사용자의 PC 에서 로그인 화면의 인증 칸에 입력하는 데에만 사용됩니다.
  • Gmail 주소는 허용 사용자 목록과 대조하는 데에만 사용됩니다.
  • 광고, 프로파일링, 제3자 제공, 판매, 인공지능 모델 학습 등 다른 목적으로 사용하지 않습니다.

3. 저장과 보관

  • Google 로그인 토큰과 연결된 Gmail 주소는 사용자 본인의 PC 설치 폴더에만 저장됩니다. 외부 서버나 다른 사람에게 전송되지 않습니다.
  • 인증 코드는 화면에 표시된 뒤 저장하지 않습니다. 메일 본문은 PC 메모리에서 처리 후 즉시 버립니다.
  • 도구 폴더를 지우면 저장된 토큰도 함께 삭제됩니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 제공·공유·판매하지 않습니다. 데이터는 Google API 와 사용자 PC 사이에서만 오갑니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 도구의 Google API 로부터 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 사용자의 권리 (연결 해제)

  • 언제든지 Google 계정 → 보안 → 서드 파티 앱 및 서비스에서 이 앱의 액세스 권한을 삭제할 수 있습니다.
  • PC 의 도구 폴더(토큰 파일 포함)를 지우면 저장된 정보가 모두 삭제됩니다.

7. 방침의 변경

내용이 바뀌면 이 페이지에 시행일과 함께 갱신합니다.

8. 문의

이 도구와 방침에 대한 문의는 앱 동의 화면에 표시된 지원 이메일로 연락해 주세요.
